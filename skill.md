# Python Function and Class Comment Format

For every new Python class or function, add a banner comment immediately before its definition. Use Python `#` comments and keep the labels and explanations in simple English.

For functions:

```python
##############################################################################
# Function Name : function_name
#
# Parameters    : parameter_name - What the parameter contains.
#
# Note          : What the function does.
##############################################################################
```

For classes, use the same banner and replace `Function Name` with `Class Name`. Describe constructor or class parameters and the class purpose. Add a function banner before each new method too.
